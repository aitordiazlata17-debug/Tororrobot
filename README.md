# TORORROBOT - Robot Mini Sumo 500g

Proyecto de robot mini sumo diseñado para la asignatura y adaptado a la normativa de **OSHWDem**.

## 👥 Componentes del Equipo
* Darío Fernández Trapero
* Aitor Díaz Lata

## 🛠️ Especificaciones Previstas
* **Dimensiones:** 10 cm x 10 cm x 5 cm
* **Peso estimado:** 480 g (Límite 500 g)
* **Control:** PCB personalizada con chip ATmega328P suelto
* **Motores:** 2x Micromotores N20 6V 600RPM
* **Tracción:** 2WD con ruedas Pololu de alta tracción
* **Alimentación:** Batería LiPo 2S 7.4V 450mAh
* **Sensores:** 2x Infrarrojos Sharp GP2Y0A21 (oponente) y 1x TCRT5000 (línea/suelo)
